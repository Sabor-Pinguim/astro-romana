# Middle stage module

The stackable bay between the Main Booster and the Cabin. Each module adds **one mounting point** (`Attach_Bay`) for one equipment module (`../../../../tools/modeling/parts/equipment.mjs`), as in [equipamentos-estagios.md](../../../../docs/resources/equipamentos-estagios.md): `Ø 1.00 m × 1.00 m` normalized, useful cavity `Ø 0.91 m × 0.84 m`. The front half sits on the `Closed` node: the builder hides it so the crew sees what is mounted inside (open cutaway); the launch pad and other outside views show it (closed stage). Real analog: stage and payload adapters such as the Orion stage adapter.

**Why tier 1:** all middle stages are identical; what changes is the equipment inside.

## 4. Low-poly model

Generated by `tools/modeling/parts/structures.mjs` (`npm run models:build:parts -- stage-module`).

### 4.1 Shape in words

The back half of a white cylinder (open toward +Z), with a dark inner wall, a black band near the top, two steel frames along the cut edges, full aluminum floor and roof decks, and a titanium hexagonal pad with a gold ring in the center of the floor: the mounting point. Closed version (`Closed` node): the front half of the shell, its black band and a small aluminum access panel.

### 4.2 Node hierarchy

```text
StageModule                 origin: bottom interface
├─ Attach_Top               (0, 1, 0)     next module
├─ Attach_Bottom            (0, 0, 0)
├─ Attach_Bay               (0, 0.1, 0)   equipment bottom plate
└─ Closed                   front half: hidden in the builder, shown in outside views
```
